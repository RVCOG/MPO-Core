## Printing Instructions
The UniFLOW printer will automatically fold the brochures if the following settings are used.
1. Flip page on short side.
2. Paper source from Tray 2. Ensure paper is regular 8.5x11.
3. Use Saddle C-Fold. If the folding option is greyed out, ensure the staple option is off.
